##  Python Quiz Application

A feature-rich interactive Quiz Application built with Python. The application provides a modern terminal-based quiz experience with randomized questions, timed answer selection, color-coded feedback, progress tracking, and a detailed final result.

### Features

-  20 Python multiple-choice questions
-  Randomized question order
-  10-second timer for each question
-  Colorful and interactive terminal interface
-  Direct A/B/C/D keyboard selection
-  Quiz progress indicator
-  Instant answer feedback
-  Final score and percentage
-  Automatic grade calculation
-  High-score storage
-  Quiz history tracking
-  Play Again option
-  Instructions section
-  User-friendly main menu

###  Technologies Used

- Python
- Random module
- OS module
- Time module
- MSVCRT
- DateTime
- File Handling

###  Project Objective

The main objective of this project is to build an interactive Python-based quiz system while practicing core Python concepts such as functions, lists, dictionaries, loops, conditional statements, file handling, randomization, user input, and modular programming.
